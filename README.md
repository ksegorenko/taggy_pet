# 🐾 TaggyPet

**TaggyPet** - сервис для поиска и идентификации домашних животных по номеру микрочипа или клейма.

Проект призван помочь владельцам потерявшихся питомцев быстрее находить своих животных, а людям, обнаружившим потерявшегося питомца, - получить информацию для поиска его владельца.

## ✨ Возможности

- **Поиск животных** — идентификация питомца по уникальному номеру микрочипа или клейма.
- **Личный кабинет** — доступ к полной о своем питомце и возможность поделиться актуальными контактами.
- **Обработки питомца** - возможность вести календарь прививок питомца
